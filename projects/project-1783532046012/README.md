# Proje Dosyaları

## config/db.js
Bu dosya, veritabanı bağlantısını tanımlar. Veritabanı adı, yol ve tablo adı belirtilir.

## config/swagger.js
Bu dosya, Swagger API dokumentasyonunu oluşturur. API adı, sürümü ve belirli rute'ları belirler.

## config/users.json
Bu dosya, kullanıcılar için kayıtlarını içerecek bir dosya. Bu dosya tamamen boş, genellikle bir veritabanı tablosu ile ilgilidir.
